# 31 - Viewers

Previous: [Install a file manager](30-file_manager.md)

---

Install a PDF viewer:

- <https://wiki.archlinux.org/title/PDF,_PS_and_DjVu>
- <https://en.wikipedia.org/wiki/Okular>

For example, install okular:

```bash
sudo pacman -S okular
```

Install an image viewer:

- <https://wiki.archlinux.org/title/List_of_applications/Multimedia#Image>
- <https://en.wikipedia.org/wiki/Gwenview>

For example, install gwenview:

```bash
sudo pacman -S gwenview
```
