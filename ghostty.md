# Ghostty

References:

- <https://wiki.archlinux.org/title/List_of_applications/Utilities#Terminal_emulators>
- <https://wiki.archlinux.org/title/Ghostty>

---

Install

```bash
sudo pacman -S --needed ghostty
```

Edit config file

```bash
nano ~/.config/ghostty/config.ghostty
```

Add

```
font-size = 15
theme = Builtin Light
background = #ffffdd
```
